# LED Panel Card

Carte Lovelace pour panneaux LED WS2812 8×8 pilotés par Home Assistant.

> Documentation complète, installation et configuration : **[djiesr/HA-LED-Status-Panel](https://github.com/djiesr/HA-LED-Status-Panel)**

---

## Installation rapide via HACS

1. HACS → Frontend → ⋮ → Dépôts personnalisés
2. URL : `djiesr/led-panel-card` — Type : **Lovelace**
3. Installer
4. Ajouter la ressource : `/hacsfiles/led-panel-card/led-panel-card.js`

> **Développeurs :** le fichier servi par HACS est `led-panel-card.js` **à la racine du dépôt** (généré par `npm run build`). Il doit être **commité** pour que l’installation HACS ne renvoie pas une erreur 404.
